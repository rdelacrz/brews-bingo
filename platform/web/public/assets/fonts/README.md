# Self-hosted Brews typography

The official https://www.rockvillebrews.com/ site uses Cormorant Garamond for display headings and DM Sans for body text. These unmodified Google Fonts WOFF2 files provide the normal-style Latin subset, variable weights 400–700. Browser system fonts supply missing glyphs. No Google/CDN requests occur at runtime.

Both fonts use the SIL Open Font License 1.1; full copyright notices and licenses are included beside the binaries.
